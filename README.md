# Agents Playground

This repository is the working codebase for the **Agents Playground** project.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Contributing

All changes should be linked to an aqua work item. Branch naming convention:

```
fix/<ITEM_ID>-<short-description>   # for defects
feature/<ITEM_ID>-<short-description>  # for requirements
```
